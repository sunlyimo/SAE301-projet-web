
# PROJET (SAE) SITE WEB 

Ce projet évalué a été réalisé dans le cadre de l'IUT en groupe de 8 personnes et était d'une durée de 5 jours.
C'est un site destiné à la gestion des courses d'orientation pour faciliter l'inscription aux courses de la part des participants, et la création de courses de la part des responsables.

Le framework Laravel était imposé.

Le premier jour, je me suis occupé de la maquette du site.
Ensuite ma partie principale a été l'inscription d'une personne dans une équipe, j'ai donc fait le front-end de la page, géré l'insertion d'un participant dans la base de données.
Nous avons utilisé Trello, un outil de gestion de projet en ligne, pour créer et voir les fonctionnalités à faire, et savoir sur quoi travaillent les camarades.

# Pour tester le projet
1. Installer Laravel et MariaDB
2. Cloner le projet sur votre ordinateur
3. Configurer le fichier `.env` avec vos informations de base de données
4. Exécuter `php artisan migrate` pour créer les tables
5. Lancer `php artisan serve` dans un terminal
6. Lancer `npm run dev` dans un second terminal
7. Ouvrir un navigateur à l'adresse `localhost:8000`
